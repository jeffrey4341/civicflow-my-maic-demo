OpenAI ChatGPT and Codex assisted research, code, review, tests, documentation, and slide/PDF production. CivicFlow runs by default as deterministic TypeScript. An optional Anthropic runtime path is disabled unless an API key is configured. The Data analysis / model training category covers rubric and evidence analysis only; no model training or fine-tuning was performed. CivicFlow MY Mobile uses AI as an assistive casework layer, not as an autonomous decision-maker. In the demo, AI is used for language detection, case classification, request summarisation, retrieval of synthetic SOP / FAQ / service-charter citations, routing recommendation, missing-information detection and citizen reply drafting. Malay, English, Chinese and Tamil inputs produce structured outputs that officers can inspect and revise.

The default judging path runs in deterministic local mode with no API key and no external model call. The TypeScript pipeline uses language heuristics, category rules, retrieval over six bundled synthetic policy documents and fixed reply templates. The optional Anthropic runtime path is disabled by default and may refine detected language, an English translation, category and urgency only when an `ANTHROPIC_API_KEY` is explicitly configured; it cannot downgrade a deterministic category-specific human gate. Policy retrieval, routing rules, missing-information checks, approval gates, reply drafting, lifecycle enforcement and audit recording remain application logic.

Human oversight is mandatory and visible. Saving an officer review does not send a reply; supervisor approval does not start work; and actionable closure requires a released reply, work in progress and a human closure note. A human-reviewed close-without-action path remains available after the required supervisor decision. A Malay flood-risk drainage case requires a documented supervisor decision. A Chinese licence request remains in the same case while the citizen supplies missing details and the revised case returns to officer review. An education or welfare case cannot advance through its outcome-sensitive path until a human officer records the welfare outcome. AI never closes cases, approves high-risk escalation, dispatches field teams or decides eligibility.

Recommendations must carry selected synthetic policy evidence or remain in manual review. Blocked transitions and human actions are recorded in a process-scoped, append-only event timeline. The demo nevertheless uses client-asserted roles and in-memory state; reset or restart clears runtime changes. "Send reply" and "start work" update the demo workflow only. There is no production authentication, notification delivery, field-work integration, formal accuracy evaluation or equal-quality guarantee across all four languages.

All cases, identities, locations and policy documents are synthetic. No real citizen data, NRICs, phone numbers, government records, private agency data, production APIs or secrets are used. The team remains responsible for the artifact, its code, disclosures and submission materials through the MAIC portal contact-of-record.
